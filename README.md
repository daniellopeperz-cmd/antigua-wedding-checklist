# Antigua Guatemala Wedding Planning Checklist

A free checklist for couples comparing wedding venues in Antigua Guatemala.
Copy it and tick off items as you plan.

## Basics
- [ ] Estimate the guest count
- [ ] Set a budget
- [ ] Pick a date (rains usually run May to October)

## Venue
- [ ] Choose ruins, a hotel, or both
- [ ] Confirm ceremony and dinner capacity
- [ ] Ask about covered backup space
- [ ] Check event end time and vendor rules
- [ ] Confirm parking and transport

## Vendors
- [ ] Wedding planner
- [ ] Photographer and videographer
- [ ] Caterer and florist

## Further reading
- [Antigua venue guide](https://daniellopezperez.com/guide/the-best-wedding-venues-in-antigua-guatemala/)
  by wedding photographers Dani & Mishka

Details can change, so confirm them with each venue.
